# Расчёт количества шагов сортировки

## Обозначения

| Символ | Смысл |
|---|---|
| `N` | число потоков-сортировщиков |
| `n` | число элементов в списке |
| `t_in` | задержка внутри шага |
| `t_out` | задержка между шагами |
| `T` | время работы |

Шаг — одна попытка поменять местами два соседних элемента.

## Один поток

Проход: `n − 1` шагов плюс конец прохода (только `t_out`).

```
S_1 = T · (n − 1) / ((n − 1) · (t_in + t_out) + t_out)  ≈  T / (t_in + t_out)
```

## Свой список

Шаг блокирует 4 соседних узла. Одновременно возможно не больше `k` шагов:

```
k = ⌊(n + 2) / 4⌋
```

```
S_own = min( N · S_1,   k · T / t_in )
```

## `Collections.synchronizedList`

Шаг блокирует весь список на `t_in`:

```
S_lib = min( N · S_1,   T / t_in )
```

Монитор насыщается при `N ≥ 1 + t_out / t_in`.

## Пример

`t_in = t_out = 100 мс`, `T = 60 с`, `n = 100`

| N | Свой список | `synchronizedList` |
|---:|---:|---:|
| 1 | 300 | 300 |
| 2 | 600 | 600 |
| 4 | 1200 | 600 |
| 8 | 2400 | 600 |
